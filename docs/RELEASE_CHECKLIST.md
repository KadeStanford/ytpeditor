# 0.5.0-alpha release record

- Release date: 2026-08-19
- Project format: Version 6; older project versions remain loadable. Version 6 adds persistent per-event timeline names.
- Toolchain: CMake 4.1.2, GCC/UCRT64 16.2, MSVC 19.38.
- Runtime baseline: Qt 6.11.1 and FFmpeg 9.0.1.
- Verification: 14/14 UCRT64 tests, Qt startup plus two multi-size visual smoke tests, portable startup, and MSVC core build/tests.
- Visual gate: native screenshots reviewed at 1024x640, 1440x900, and 1920x1080, including YTP, Remix, compact responsive behavior, and Dual monitors.
- Performance gate: a 100,000-event sequence validates within the 30-second integration budget; the timeline UI virtualizes to its visible range.
- Privacy gate: transcription and phonetic search are local-only. No telemetry, network transcription, or model download code is present.
- Packaging gate: portable ZIP and current-user setup EXE are generated by `tools/package-alpha.ps1`; hashes are recorded in `dist/SHA256SUMS.txt`.
- Licensing gate: no Whisper model is bundled. The existing GPL FFmpeg redistribution warning in `THIRD_PARTY_NOTICES.md` still applies before public distribution.
